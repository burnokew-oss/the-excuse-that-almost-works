One line of plain text — the excuse a gamer texts their boss to skip work
on GTA 6 launch week, written to read like a real text sent in a hurry:

> Hi, my dentist moved my root canal to this morning, I'll be numb and useless till lunch

A moved dental appointment: specific, boring, and verifiable-sounding, and
the laugh comes from its own logic — a numb employee is a useless employee.
No dead grandmother, no flat tyre, no sudden fever, and no mention of games
anywhere. Seventeen words, no setup, no explanation, no signature.

## Run it

```sh
python3 main.py
```

`main.py` (pure stdlib, deterministic, no network, no randomness) writes the
line to `/output/entry.txt`. Output: 87 characters, 17 words, 1 line, UTF-8,
within the 1–140 character gate and the 20-word cap.
